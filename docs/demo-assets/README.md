# Demo source

Do not commit video here — it is large and usually not yours to redistribute.
Commit a `source.txt` with the URL of the clip you demo with instead, so
everyone on the team rehearses against the same footage.

What makes a good demo source:

- 5–20 minutes. Long enough that finding moments is impressive, short enough
  that transcription finishes while you talk.
- One speaker, clearly miked. Multi-speaker recordings need diarisation, which
  is not implemented.
- Contains at least one question, one specific number, and one argument — those
  are what the scorer is looking for, and a source without them produces clips
  that are honest and dull.
- Has visible dead air somewhere. When the planner skips it, that is the proof
  it is choosing rather than chopping.
